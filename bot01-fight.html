招式

多指同時拖方塊，上方的 P1 會同步動作。拖「腰」可以前進後退或蹲下，把腰快速往上甩會蹬地跳起來，拖「頭」可以低頭閃；雙腳一起抬起來會跌坐在地上，放開腳就會站回來；手腳拖不出可及範圍，要打更遠就先拖腰靠近。按「錄」再在面板上拖出一套動作（最長 2.5 秒，放開 0.5 秒後自動存檔），之後按「招式」就能一鍵使出，動作會依面向自動左右翻轉。被打中時方塊會被撞開：手指圈變紅表示快脫手，出現「重抓」就放開手指再抓一次。方塊變紅並出現倒數弧就是硬直：打中或被擋下的那隻手腳會軟掉一下，被打中則全身短暫失控。

引擎結構說明
  • 物理：Matter.js。每個角色是 14 個剛體（頭、軀幹、上臂×2、前臂×2、手×2、大腿×2、小腿×2、腳×2）用長度 0 的關節 constraint 接起來的布娃娃；同一人的部件彼此不碰撞，和對手的每個部件、地面都會碰撞。每影格跑 4 個物理子步，薄的手掌和前臂才不會一步就穿過對方的手。
  • 站立與重力：至少一腳踩在地上、而且軀幹掉到站姿高度以下時，腿才會往上頂住（抵銷重力的支撐力 + 彈簧 + 阻尼），再加扶正扭矩；雙腳一離地（或被打飛到站姿高度以上）就沒有任何支撐，純粹受重力落下。手腳的拖曳目標被限制在肩、髖可及的範圍內，腰只能蹲、頭只能低，所以拖曳不會把自己吊起來；把腰甩到站姿線以上時，只要腳還在地上就會蹬地跳起，離地後純粹是拋物線。面向會跟著對手的位置自動翻轉。
  • 操作：手指抓住節點時，建立一條「手指 → 剛體」的彈性 constraint，CPU 也是用同一套 API 下指令。節點被衝擊推離手指太遠就自動脫手，必須重抓。
  • 命中：碰撞開始事件裡，只有「手或腳」打到「對方的頭或身體」且沿法線的相對速度夠快才扣血；慢慢推不算。對方的拳頭先碰到你的前臂就打不到頭，這就是格擋，但手臂會被推歪。
  • 硬直：打中對方後那隻手腳軟掉 0.45 秒；被對方手腳擋下時攻擊方軟 0.4 秒、擋的那隻只軟 0.15 秒，所以防守方有反擊空檔；被打中的人全身失控 0.25 到 0.55 秒（看傷害），站位也不穩，但 0.8 秒內連續被打硬直減半，避免無限連段。硬直中的節點手指還抓著，只是拉不動，面板上會顯示倒數弧。
  • 預錄招式：錄製時每影格記下手指抓住的節點與目標位置（相對軀幹、依面向正規化，腰則相對起手位置），播放時用同一套抓取 API 重播，所以硬直、脫手、格擋都照常生效。三招存在瀏覽器的 localStorage。
  • CPU：狀態機（靠近 → 舉手防禦 → 出拳/踢 → 被打後縮頭或後退），難度決定出手間隔、出拳速度、舉手機率與脫手後重抓的反應時間。
